# LabLink — About Page

A standalone HTML page describing the LabLink project: the problem it solves, how the matching system works, and the AI layer that powers semantic matching.

## What's inside

`about.html` is a single self-contained file (HTML + CSS, no external dependencies). Open it directly in any browser, no build step required.

## Sections

- **The problem** — why students struggle to find research opportunities, and why labs struggle to find qualified candidates
- **How it works** — the two-layer scoring system: structured rule-based matching plus AI semantic matching
- **The AI layer** — how the Cohere Embed API turns research statements into comparable semantic scores
- **By the numbers** — quick stats on the underlying data model (research fields, sub-disciplines, scoring layers)

## Usage

Clone the repo and open `about.html` in a browser, or enable GitHub Pages on this repo to get a live shareable link.
